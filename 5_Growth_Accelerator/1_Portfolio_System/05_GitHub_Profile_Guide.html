Profile Checklist

Before Applying to Jobs:
  • Profile picture (professional headshot)
  • Bio (2-3 lines, focus on data engineering)
  • Location and company (if relevant)
  • Profile README with structure above
  • 6 pinned repositories with good descriptions
  • Green contribution graph (last 3-6 months)
  • All repos have proper README.md
  • No placeholder/incomplete repos visible
  • Topics/tags added to all projects

Red Flags to Avoid

  • Empty profile (no README)
  • No activity (white contribution graph)
  • Only forked repos (no original work)
  • Repos with no README or documentation
  • Generic commit messages ("update" or "fixed stuff")
  • Projects with no clear purpose
  • Incomplete projects left visible

When Recruiters Visit

They spend 30-60 seconds. Make it count:

  • Profile README loads first (hook them here)
  • Pinned repos show immediately (best 6 projects)
  • Contribution graph visible (shows consistency)
  • Click into 1-2 repos (README quality matters)

Optimization Goal: In 60 seconds, they should see:

  • What you specialize in (data engineering on Databricks)
  • Evidence of execution (green graph, quality repos)
  • Production-level thinking (CI/CD, documentation, structure)
  • Clear contact info (LinkedIn, email)
